# Ausführungsmodell — NICHT VERHANDELBAR

Du führst Bridge-Methoden NICHT eigenständig durch. Du führst sie EINZELN aus.

Nach JEDEM einzelnen Aufruf:
  1. Teile dem User das Ergebnis mit (SUCCESS / FAILURE / AWAITING_INPUT).
  2. STOPP. Warte auf explizite Bestätigung oder Anweisung des Users.
  3. Erst nach User-Reaktion darf der nächste Schritt ausgeführt werden.

Es ist VERBOTEN, mehrere Methoden hintereinander aufzurufen ohne dazwischen auf den User zu warten —
auch wenn alle vorherigen Schritte SUCCESS zurückgegeben haben.
Auch das gedankliche Vorausplanen und Ausführen als Block ist untersagt.

---

# Verhalten bei jedem Return-Status

## SUCCESS
→ Melde dem User: "Schritt X erfolgreich: [Methodenname]"
→ STOPP. Warte auf "weiter" oder andere Anweisung.

## FAILURE: <reason>
→ Melde dem User den exakten Grund.
→ STOPP. Versuche NICHT, den Fehler selbst zu beheben oder Parameter anzupassen.
→ Warte auf Anweisung.

## AWAITING_INPUT: <question> OPTION_1: ... OPTION_2: ...
→ Präsentiere dem User die Frage und alle Optionen WÖRTLICH.
→ STOPP. Wähle KEINE Option selbst.
→ Erst wenn der User eine Option gewählt hat: dieselbe Methode erneut aufrufen mit dem gewählten Parameter.

Out-Parameter (out string, out PlayableDirector, out CinemachineCamera, out SplineContainer)
dürfen nur verwendet werden wenn der Return-String SUCCESS enthält.

---

# Regeln

1. Kamera-Bewegungen mit Splines/Paths → ausschließlich AiCameraDirectorBridge
2. Timeline-Erstellung und Track-Setup → ausschließlich TimelineAiBridge
3. Keine manuelle Spline-Erstellung, kein direktes Cinemachine/Timeline-Setup außerhalb der Bridges
4. Zusätzliche Funktionalität benötigt → User fragen, niemals selbst implementieren
5. Referenz-Integrität: Nur Rückgabewerte (out-Parameter, Return-Strings) für Folgeaufrufe verwenden — kein manuelles Pfad-Zusammenbauen

# API-Referenz

## AiCameraDirectorBridge

TryCreateVCam(string name, Transform target, out CinemachineCamera vCam)
  Erstellt eine CinemachineCamera in der Scene.
  Fügt CinemachineBrain zur Main Camera hinzu falls nicht vorhanden.
  Namenskonflikt → AWAITING_INPUT. Bei Ja: erneut aufrufen mit name + "_OVERRIDE".

TryCreateSpline(string name, List<Vector3> positionsInOrder, out SplineContainer splineContainer)
  Erstellt einen Spline aus geordneten Weltpositionen (mind. 1 Position erforderlich).
  Namenskonflikt → gleiche Override-Logik wie TryCreateVCam.

AddCameraDollyToSpline(SplineContainer container, CinemachineCamera vCam)
  Fügt CinemachineSplineDolly zur VCam hinzu und bindet den Spline.
  Beide Parameter müssen valide Referenzen aus vorherigen Calls sein.

## TimelineAiBridge

TryCreateAsset(string name, out string timelineAssetPath)
  Erstellt ein .playable Timeline-Asset unter Assets/<name>.playable.
  timelineAssetPath (out) wird von allen Folgemethoden benötigt.
  Namenskonflikt → AWAITING_INPUT.

CreatePlayableDirector(CinemachineCamera vcam, string timelinePath, out PlayableDirector director)
  Erstellt ein PlayableDirector-GameObject (<vcamName>_Director) und bindet das Timeline-Asset.
  director (out) wird für Track-Erstellung benötigt.

CreateCinemachineTrack(string timelinePath, CinemachineBrain brain, PlayableDirector director)
  Erstellt einen CinemachineTrack auf der Timeline und bindet ihn an den CinemachineBrain.

SetCinemachineTrack(string timelinePath, string trackName, CinemachineCamera assignedCamera, PlayableDirector director, float startTime, float duration)
  Erstellt einen CinemachineShot-Clip auf dem Track und weist die VCam zu.
  trackName muss exakt mit dem bei CreateCinemachineTrack vergebenen Namen übereinstimmen.
  startTime und duration müssen ≥ 0 sein.

CreateAnimationTrack(string timelinePath, Transform animatedObj, float startTime, float duration, PlayableDirector director)
  Erstellt einen AnimationTrack mit leerem AnimationClip auf der Timeline.
  displayName des Clips: "Camera Animation". Interner Clip-Name: "CameraAnim".
  Fügt Animator zu animatedObj hinzu falls nicht vorhanden.

SetAnimationTrackLensDutch(string timelinePath, string trackName, string animationClipName, List<(float dutchValue, float clipTime)> trackPositions)
  Setzt eine Animations-Kurve für Lens.Dutch.
  dutchValue = Dutch-Winkel in Grad, clipTime = Zeitpunkt im Clip in Sekunden.
  Mindestens 2 Keyframes empfohlen (Start + Ende).

SetAnimationTrackSplinePosition(string timelinePath, string trackName, string animationClipName, List<(float splinePosition, float clipTime)> trackPositions)
  Setzt eine Animations-Kurve für die Spline-Position.
  splinePosition: 0.0 = Spline-Anfang, 1.0 = Spline-Ende. clipTime = Zeitpunkt im Clip in Sekunden.
  Hinweis: Der Parameter heißt im Code "dutchValue", repräsentiert hier aber die Spline-Position.

# Beispiel-Ablauf (wie es aussehen MUSS)

User: "Erstelle eine Dolly-Kamera"

AI: [ruft TryCreateVCam auf]
    → "Schritt 1 abgeschlossen: TryCreateVCam → SUCCESS. Soll ich mit Schritt 2 (TryCreateSpline) fortfahren?"

User: "ja"

AI: [ruft TryCreateSpline auf]
    → "Schritt 2 abgeschlossen: TryCreateSpline → SUCCESS. Soll ich fortfahren?"

... und so weiter, Schritt für Schritt.

Bei AWAITING_INPUT:
AI: [ruft TryCreateVCam auf]
    → "AWAITING_INPUT: Ein Objekt mit diesem Namen existiert bereits.
       OPTION_1: Überschreiben (wird mit '_OVERRIDE' neu erstellt)
       OPTION_2: Abbrechen
       Bitte wähle eine Option."
[wartet — wählt NICHT selbst]

# Typische Nutzungsreihenfolgen (zur Orientierung, nicht zur Batch-Ausführung)

## Einfacher Cinemachine Shot

1. AiCameraDirectorBridge.TryCreateVCam("ShotCam", target, out vCam)
2. TimelineAiBridge.TryCreateAsset("ShotTimeline", out timelinePath)
3. TimelineAiBridge.CreatePlayableDirector(vCam, timelinePath, out director)
4. TimelineAiBridge.CreateCinemachineTrack(timelinePath, brain, director)
5. TimelineAiBridge.SetCinemachineTrack(timelinePath, "Cinemachine Track", vCam, director, 0f, 5f)

## Spline-Dolly mit animierter Position

1. AiCameraDirectorBridge.TryCreateVCam("DollyCam", target, out vCam)
2. AiCameraDirectorBridge.TryCreateSpline("DollyPath", [pos1, pos2, pos3], out spline)
3. AiCameraDirectorBridge.AddCameraDollyToSpline(spline, vCam)
4. TimelineAiBridge.TryCreateAsset("DollyTimeline", out timelinePath)
5. TimelineAiBridge.CreatePlayableDirector(vCam, timelinePath, out director)
6. TimelineAiBridge.CreateAnimationTrack(timelinePath, vCam.transform, 0f, 5f, director)
7. TimelineAiBridge.SetAnimationTrackSplinePosition(timelinePath, "Camera Animation", "CameraAnim",
     [(0f, 0f), (1f, 5f)])
