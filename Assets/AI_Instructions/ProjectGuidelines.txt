# Execution Model — STRICTLY MANDATORY

YOU MUST NEVER ASSUME WHAT THE USER WOULD CHOOSE.
YOU MUST NEVER CALL MULTIPLE BRIDGE METHODS IN ONE TURN IF ANY OF THEM DID NOT RETURN 'SUCCESS'.

As soon as a return string does NOT start with "SUCCESS", your response must end immediately.
You may not execute further logic, call further tools, or make any assumptions.

---

# Behavior for Each Return Status

## SUCCESS
→ Report to the user: "✓ [MethodName] successful" → proceed to the next step.

## FAILURE: <reason>
⛔ BRIDGE FAILURE: [MethodName]
[exact reason from the return string]
Please provide an instruction on how to proceed.

No further tool calls. No suggested fixes. No parameter adjustments.
Only the user has enough context to resolve errors. Any autonomous fix corrupts the scene.

## AWAITING_INPUT: <question> OPTION_1: ... OPTION_2: ...
🔵 BRIDGE AWAITING INPUT: [MethodName]
[question from the return string]
Please choose an option:
  👉 OPTION_1: [description]
  👉 OPTION_2: [description]

No further tool calls. Do NOT choose an option yourself.
Wait for the user's explicit choice, then call the same method again with that parameter.

# Rules

1. Camera movements with splines/paths → exclusively AiCameraDirectorBridge
2. Timeline creation and track setup → exclusively TimelineAiBridge
3. No manual spline creation, no direct Cinemachine/Timeline setup outside the bridges
4. Additional functionality needed → ask the user, never implement it yourself
5. Reference integrity: only use GIDs and return values from previous calls — never manually assemble paths or names

## Scene Structure (IMPORTANT)
- There is exactly ONE director and ONE timeline per scene. Store directorGlobalId and timelineAssetName immediately after creation — they are required for every subsequent call.
- There is exactly ONE CinemachineTrack. Never call CreateCinemachineTrack more than once. Use SetCinemachineTrack to add shots to the existing track.
- When a camera has an animation covering e.g. seconds 8–14, call SetCinemachineTrack with startTime=8, duration=6 to make that camera active for exactly that window.

## Animation Timing
Animations must use realistic durations. A camera move that should feel like 5 seconds must have keyframes spanning 5 seconds (clipTime 0→5), not 0→0.1. Fast keyframes that blaze through in a few frames are wrong.

---

# Forbidden Patterns

❌ **Script wrapping:** NEVER generate a C# script or CommandScript that chains multiple bridge calls together. Bridge methods must always be called as individual direct tool calls — never bundled into a script that executes as one block. A script bypasses the entire gate system and makes failure handling and AWAITING_INPUT impossible.

❌ **Auto-Override:** Getting AWAITING_INPUT and immediately calling the method again with "_OVERRIDE" without asking the user.

❌ **Batch calls:** Sending multiple Bridge calls without validating each result individually first.

❌ **Creating a second CinemachineTrack** instead of adding a shot to the existing one.

# API Reference

## Reference System
- out string *GlobalId → GID of the created scene object; store and reuse for all subsequent calls
- string *GlobalId params → must be a GID from a previous bridge call
- string timelineAssetName → plain name string (not a GID), used to look up the .playable file

## AiCameraDirectorBridge

TryCreateVCam(string name, string targetGlobalId, out string vCamGlobalId, out string brainGlobalId)
  Creates a CinemachineCamera. Adds CinemachineBrain to Main Camera if missing.
  Returns vCamGlobalId and brainGlobalId — store both.
  Name conflict → AWAITING_INPUT. If yes: call again with name + "_OVERRIDE".

TryCreateSpline(string name, List<Vector3> positionsInOrder, out string splineContainerGlobalId)
  Creates a spline from ordered world positions (min. 1). Name conflict → same override logic.

AddCameraDollyToSpline(string containerGlobalId, string vCamGlobalId)
  Adds CinemachineSplineDolly to the VCam and binds the spline.

## TimelineAiBridge

TryCreateAsset(string name, out string timelineAssetName)
  Creates a .playable asset at Assets/<name>.playable. Store timelineAssetName for all future calls.
  Name conflict → AWAITING_INPUT.

CreatePlayableDirector(string vCamGlobalId, string timelineAssetName, out string directorGlobalId)
  Creates the scene's PlayableDirector. Store directorGlobalId — needed for every track method.

CreateCinemachineTrack(string timelineAssetName, string brainGlobalId, string directorGlobalId)
  Creates the ONE CinemachineTrack for the scene. Call this only once per scene.

SetCinemachineTrack(string timelineAssetName, string trackName, string assignedCameraGlobalId, string directorGlobalId, float startTime, float duration)
  Adds a CinemachineShot to the existing track for the given time window.
  trackName = "Cinemachine Track". startTime and duration must be ≥ 0.

CreateAnimationTrack(string timelineAssetName, string animatedObjGlobalId, float startTime, float duration, string directorGlobalId)
  Creates an AnimationTrack with an empty clip. displayName: "Camera Animation", clip name: "CameraAnim".
  Adds Animator to animatedObj if missing.

SetAnimationTrackLensDutch(string timelineAssetName, string trackName, string animationClipName, List<(float dutchValue, float clipTime)> trackPositions)
  Sets animation curve for Lens.Dutch. dutchValue = degrees, clipTime = seconds in clip.
  Use realistic time spans (e.g. 0→5s for a 5-second dutch effect). Min. 2 keyframes.

SetAnimationTrackSplinePosition(string timelineAssetName, string trackName, string animationClipName, List<(float splinePosition, float clipTime)> trackPositions)
  Sets animation curve for spline position (0.0=start, 1.0=end).
  Use realistic time spans matching the intended move duration. Min. 2 keyframes.
  Note: parameter is named "dutchValue" in code but represents spline position.

# Typical Usage Sequences

## Simple Cinemachine Shot
1. TryCreateVCam("ShotCam", targetGlobalId, out vCamGlobalId, out brainGlobalId)
2. TryCreateAsset("SceneTimeline", out timelineAssetName)
3. CreatePlayableDirector(vCamGlobalId, timelineAssetName, out directorGlobalId)
4. CreateCinemachineTrack(timelineAssetName, brainGlobalId, directorGlobalId)
5. SetCinemachineTrack(timelineAssetName, "Cinemachine Track", vCamGlobalId, directorGlobalId, 0f, 5f)

## Spline-Dolly with Animated Position
1. TryCreateVCam("DollyCam", targetGlobalId, out vCamGlobalId, out brainGlobalId)
2. TryCreateSpline("DollyPath", [pos1, pos2, pos3], out splineGlobalId)
3. AddCameraDollyToSpline(splineGlobalId, vCamGlobalId)
4. TryCreateAsset("SceneTimeline", out timelineAssetName)
5. CreatePlayableDirector(vCamGlobalId, timelineAssetName, out directorGlobalId)
6. CreateCinemachineTrack(timelineAssetName, brainGlobalId, directorGlobalId)
7. SetCinemachineTrack(timelineAssetName, "Cinemachine Track", vCamGlobalId, directorGlobalId, 0f, 8f)
8. CreateAnimationTrack(timelineAssetName, vCamGlobalId, 0f, 8f, directorGlobalId)
9. SetAnimationTrackSplinePosition(timelineAssetName, "Camera Animation", "CameraAnim", [(0f,0f),(1f,8f)])
