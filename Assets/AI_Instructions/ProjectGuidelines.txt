# Execution Model — STRICTLY MANDATORY

YOU MUST NEVER ASSUME WHAT THE USER WOULD CHOOSE.
YOU MUST NEVER CALL MULTIPLE BRIDGE METHODS IN ONE TURN IF ANY OF THEM DID NOT RETURN 'SUCCESS'.

## The Golden Rule
As soon as a return string does NOT start with "SUCCESS", your response must end immediately.
You may not execute further logic, call further tools, or make any assumptions.

---

# Behavior for Each Return Status

## SUCCESS
→ Report to the user: "✓ [MethodName] successful"
→ Proceed directly to the next step without asking for confirmation.

## FAILURE: <reason>
Write the user exactly this message (replace values):

⛔ BRIDGE FAILURE: [MethodName]
[exact reason from the return string]

Please provide an instruction on how to proceed.

After that: no further tool calls, no suggested fixes, no parameter adjustments.
You do not have enough context to correctly resolve the error — only the user has that context.
Any autonomous fix attempt will result in a corrupted scene state.

## AWAITING_INPUT: <question> OPTION_1: ... OPTION_2: ...
Write the user exactly this message (replace values, present options clearly as a choice):

---
🔵 BRIDGE AWAITING INPUT: [MethodName]
[question from the return string]

Please choose an option:
- OPTION_1: [description of option 1]
- OPTION_2: [description of option 2]
---

After that: no further tool calls, no assumption about what the user would choose.
Wait until the user explicitly names an option, then call the same method again with the chosen parameter.

---

# Forbidden Patterns (Anti-Patterns)

❌ **The "Auto-Override" Pattern:**
Call: `TryCreateAsset("Name")` → Return: `AWAITING_INPUT: Override?`
Wrong reaction: Immediately calling `TryCreateAsset("Name_OVERRIDE")` in the same turn.
Correct reaction: Present the question to the user and wait for their answer.

❌ **The "Batch-Ignoring" Pattern:**
Sending multiple Bridge calls in one tool chain without waiting for the result of the previous call.
As an LLM, you must validate the output of each call individually before generating the next one.

---

# Rules

1. Camera movements with splines/paths → exclusively AiCameraDirectorBridge
2. Timeline creation and track setup → exclusively TimelineAiBridge
3. No manual spline creation, no direct Cinemachine/Timeline setup outside the bridges
4. Additional functionality needed → ask the user, never implement it yourself
5. Reference integrity: only use return values (out parameters, return strings) for subsequent calls — manually assembling paths is forbidden

# API Reference

## Reference System
All scene object references are passed and returned as GlobalObjectId strings (GIDs).
- out string *GlobalId → GID of the created scene object; store and pass to subsequent calls
- string *GlobalId params → must be a GID returned by a previous bridge call
- string timelineAssetName → plain asset name string (not a GID), used to look up the .playable file

## AiCameraDirectorBridge

TryCreateVCam(string name, string targetGlobalId, out string vCamGlobalId, out string brainGlobalId)
  Creates a new CinemachineCamera in the scene.
  Automatically adds CinemachineBrain to the Main Camera if not present.
  Returns vCamGlobalId and brainGlobalId — both are needed for subsequent calls.
  Name conflict → AWAITING_INPUT. If yes: call again with name + "_OVERRIDE".

TryCreateSpline(string name, List<Vector3> positionsInOrder, out string splineContainerGlobalId)
  Creates a spline from an ordered list of world positions (min. 1 position required).
  Name conflict → same override logic as TryCreateVCam.

AddCameraDollyToSpline(string containerGlobalId, string vCamGlobalId)
  Adds CinemachineSplineDolly to the VCam and binds the spline.
  Both GIDs must come from previous bridge calls.

## TimelineAiBridge

TryCreateAsset(string name, out string timelineAssetName)
  Creates a .playable Timeline asset at Assets/<name>.playable.
  timelineAssetName (out) is a plain name string — required by all subsequent methods.
  Name conflict → AWAITING_INPUT.

CreatePlayableDirector(string vCamGlobalId, string timelineAssetName, out string directorGlobalId)
  Creates a PlayableDirector GameObject (<vcamName>_Director) and binds the Timeline asset.
  directorGlobalId (out) is required for all track methods.

CreateCinemachineTrack(string timelineAssetName, string brainGlobalId, string directorGlobalId)
  Creates a CinemachineTrack on the Timeline and binds it to the CinemachineBrain.
  brainGlobalId and directorGlobalId must be valid GID strings from previous calls.

SetCinemachineTrack(string timelineAssetName, string trackName, string assignedCameraGlobalId, string directorGlobalId, float startTime, float duration)
  Creates a CinemachineShot clip on the track and assigns the VCam.
  trackName must exactly match the name given in CreateCinemachineTrack.
  assignedCameraGlobalId and directorGlobalId must be valid GID strings from previous calls.
  startTime and duration must be ≥ 0.

CreateAnimationTrack(string timelineAssetName, string animatedObjGlobalId, float startTime, float duration, string directorGlobalId)
  Creates an AnimationTrack with an empty AnimationClip on the Timeline.
  animatedObjGlobalId and directorGlobalId must be valid GID strings from previous calls.
  Clip displayName: "Camera Animation". Internal clip name: "CameraAnim".
  Adds Animator to animatedObj if not present.

SetAnimationTrackLensDutch(string timelineAssetName, string trackName, string animationClipName, List<(float dutchValue, float clipTime)> trackPositions)
  Sets an animation curve for Lens.Dutch.
  dutchValue = Dutch angle in degrees, clipTime = time in seconds within the clip.
  Minimum 2 keyframes recommended (start + end).

SetAnimationTrackSplinePosition(string timelineAssetName, string trackName, string animationClipName, List<(float splinePosition, float clipTime)> trackPositions)
  Sets an animation curve for the spline position.
  splinePosition: 0.0 = spline start, 1.0 = spline end. clipTime = time in seconds within the clip.
  Note: The parameter is named "dutchValue" in code but represents the spline position here.

# Typical Usage Sequences

## Simple Cinemachine Shot

1. AiCameraDirectorBridge.TryCreateVCam("ShotCam", targetGlobalId, out vCamGlobalId, out brainGlobalId)
2. TimelineAiBridge.TryCreateAsset("ShotTimeline", out timelineAssetName)
3. TimelineAiBridge.CreatePlayableDirector(vCamGlobalId, timelineAssetName, out directorGlobalId)
4. TimelineAiBridge.CreateCinemachineTrack(timelineAssetName, brainGlobalId, directorGlobalId)
5. TimelineAiBridge.SetCinemachineTrack(timelineAssetName, "Cinemachine Track", vCamGlobalId, directorGlobalId, 0f, 5f)

## Spline-Dolly with Animated Position

1. AiCameraDirectorBridge.TryCreateVCam("DollyCam", targetGlobalId, out vCamGlobalId, out brainGlobalId)
2. AiCameraDirectorBridge.TryCreateSpline("DollyPath", [pos1, pos2, pos3], out splineGlobalId)
3. AiCameraDirectorBridge.AddCameraDollyToSpline(splineGlobalId, vCamGlobalId)
4. TimelineAiBridge.TryCreateAsset("DollyTimeline", out timelineAssetName)
5. TimelineAiBridge.CreatePlayableDirector(vCamGlobalId, timelineAssetName, out directorGlobalId)
6. TimelineAiBridge.CreateAnimationTrack(timelineAssetName, vCamGlobalId, 0f, 5f, directorGlobalId)
7. TimelineAiBridge.SetAnimationTrackSplinePosition(timelineAssetName, "Camera Animation", "CameraAnim",
     [(0f, 0f), (1f, 5f)])   // Spline start → end over 5 seconds
