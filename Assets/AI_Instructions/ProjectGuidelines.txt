# Regeln
                                                                                                                                                                            
    1. Kamera-Bewegungen mit Splines/Paths → ausschließlich AiCameraDirectorBridge
    2. Timeline-Erstellung und Track-Setup → ausschließlich TimelineAiBridge                                                                                                      
    3. Keine manuelle Spline-Erstellung, kein direktes Cinemachine/Timeline-Setup außerhalb der Bridges                                                                           
    4. Zusätzliche Funktionalität benötigt → User fragen bevor selbst implementiert wird    
                                                                                                                                                                                    
# Return Value System                                                                                                                                                           
                                                                                                                                                                                
    Jede Methode gibt einen string zurück im Format [[PROMPTRETURN]] <STATUS>:                                                                                                    
                                                                                                                                                                                    
    - SUCCESS — Aktion erfolgreich abgeschlossen. Weiter mit dem Plan.                                                                                                            
    - FAILURE: <reason> — Aktion abgebrochen. <reason> enthält Kontext, bitte lesen und berücksichtigen bevor weitergemacht wird.
    - AWAITING_INPUT: <question> OPTION_1: ... OPTION_2: ... — User-Input erforderlich. Optionen dem User präsentieren, auf Antwort warten, dann dieselbe Methode erneut mit dem  
    entsprechenden Parameter aufrufen.                                                                                                                                            
                                                                                                                                                                                
# Out Parameters                                                                                                                                                                
                  
    Methoden geben erstellte Objekte zusätzlich per out zurück:                                                                                                                   
    - out string → AssetPath des erstellten Assets (z.B. "Assets/MyTimeline.playable")
    - out PlayableDirector, out CinemachineCamera, out SplineContainer → direkte Referenz auf das erstellte Scene-Objekt                                                          
                                                                                                                      
    Wichtig: Out-Parameter nur verwenden wenn der Return-String SUCCESS enthält.                                                                                                  
                                                                                                                                                                                
# Methoden-Erklärung:                                                                                                                                                                       
  
    ## AiCameraDirectorBridge                                                                                                                                                        
           
        1)              
        TryCreateVCam(string name, Transform target, out CinemachineCamera vCam)
                                                                                                                                                                                
        Erstellt eine neue CinemachineCamera in der Scene. Fügt automatisch CinemachineBrain zur Main Camera hinzu falls nicht vorhanden. Bei Namenskonflikt → AWAITING_INPUT. Erneut 
        aufrufen mit name + "_OVERRIDE" bei Ja.                                                                                                                                       
                                                                                                                                                                                
        2)
        TryCreateSpline(string name, List<Vector3> positionsInOrder, out SplineContainer splineContainer)                                                                             
   
        Erstellt einen Spline aus einer geordneten Liste von Weltpositionen als Knoten (in richtiger reihenfolge). Gleiche Override-Logik wie TryCreateVCam. Mindestens 1 Position erforderlich.                 
                  
        3)
        AddCameraDollyToSpline(SplineContainer container, CinemachineCamera vCam)  
                                                                                                          
        Fügt CinemachineSplineDolly zur VCam hinzu und bindet den Spline. Beide Parameter müssen valide Referenzen aus vorherigen Calls sein.                                         
   
    ## TimelineAiBridge
    
        1)
        TryCreateAsset(string name, out string timelineAssetPath)

        Erstellt ein neues .playable Timeline-Asset unter Assets/<name>.playable. Bei Namenskonflikt → AWAITING_INPUT. timelineAssetPath enthält den vollständigen AssetPath bei      
        SUCCESS — dieser wird von allen folgenden Methoden benötigt.
                                                                                                                                                                                
        2)
        CreatePlayableDirector(CinemachineCamera vcam, string timelinePath, out PlayableDirector director)

        Erstellt ein PlayableDirector GameObject in der Scene (Name: <vcamName>_Director) und bindet das Timeline-Asset. Erfordert valide VCam-Referenz. director out-Parameter wird  
        für Track-Erstellung benötigt.
                                                                                                                                                                                
        3)
        CreateCinemachineTrack(string timelinePath, CinemachineBrain brain, PlayableDirector director)                                                                                
       
        Erstellt einen CinemachineTrack auf der Timeline und bindet ihn an den CinemachineBrain. Brain und Director müssen valide Referenzen sein.                                    
                  
        4)
        SetCinemachineTrack(string timelinePath, string trackName, CinemachineCamera assignedCamera, PlayableDirector director, float startTime, float duration)                      
        
        Erstellt einen CinemachineShot-Clip auf einem bestehenden CinemachineTrack und weist die VCam zu. trackName muss mit dem bei CreateCinemachineTrack vergebenen Namen          
        übereinstimmen. startTime und duration müssen ≥ 0 sein.
        
        5)                                                                                                                                                                    
        CreateAnimationTrack(string timelinePath, Transform animatedObj, float startTime, float duration, PlayableDirector director)                                                  
        
        Erstellt einen AnimationTrack mit einem leeren AnimationClip (displayName: "Camera Animation") auf der Timeline. Fügt Animator zum animatedObj hinzu falls nicht vorhanden.   
        Clip-Name ist aktuell fix "CameraAnim".
        
        6)                                                                                                                                                                        
        SetAnimationTrackLensDutch(string timelinePath, string trackName, string animationClipName, List<(float dutchValue, float clipTime)> trackPositions)                          
   
        Setzt eine Animations-Kurve für Lens.Dutch auf einem bestehenden AnimationClip. dutchValue = Dutch-Winkel in Grad, clipTime = Zeitpunkt im Clip in Sekunden. Mindestens 2     
        Keyframes empfohlen (Start + Ende).
                           
        7)                                                                                                                                                     
        SetAnimationTrackSplinePosition(string timelinePath, string trackName, string animationClipName, List<(float dutchValue, float clipTime)> trackPositions)                     
        
        Setzt eine Animations-Kurve für m_SplineSettings.Position (0–1 entlang des Splines). dutchValue ist hier die Spline-Position (0 = Anfang, 1 = Ende), clipTime = Zeitpunkt im  
        Clip.           
                                                                                                                                                                                
# Typische Nutzungsreihenfolgen
                                                                                                                                                                                
    Kamera mit Cinemachine Shot aufsetzen:
                                                                                                                                                                                
    1. AiCameraDirectorBridge.TryCreateVCam("ShotCam", target, out vCam)
     → SUCCESS                                                                                                                                                                  
                  
    2. TimelineAiBridge.TryCreateAsset("ShotTimeline", out timelinePath)                                                                                                          
     → SUCCESS    
                                                                                                                                                                                
    3. TimelineAiBridge.CreatePlayableDirector(vCam, timelinePath, out director)
     → SUCCESS
    
    4. TimelineAiBridge.CreateCinemachineTrack(timelinePath, brain, director)                                                                                                     
              
    5. TimelineAiBridge.SetCinemachineTrack(timelinePath, "Cinemachine Track", vCam, director, 0f, 5f)                                                                            
     → SUCCESS                                                                                                                                                                  
              
    Kamera mit Spline-Dolly und animierter Position:                                                                                                                              
                                                                                                                                                                                
    1. AiCameraDirectorBridge.TryCreateVCam("DollyCam", target, out vCam)
     → SUCCESS                                                                                                                                                                  
                  
    2. AiCameraDirectorBridge.TryCreateSpline("DollyPath", [pos1, pos2, pos3], out spline)                                                                                        
     → SUCCESS    
                                                                                                                                                                                
    3. AiCameraDirectorBridge.AddCameraDollyToSpline(spline, vCam)
     → SUCCESS
                                                                                                                                                                                
    4. TimelineAiBridge.TryCreateAsset("DollyTimeline", out timelinePath)
     → SUCCESS                                                                                                                                                                  
                  
    5. TimelineAiBridge.CreatePlayableDirector(vCam, timelinePath, out director)                                                                                                  
     → SUCCESS
                                                                                                                                                                                
     → SUCCESS                                                                            
              
    7. TimelineAiBridge.SetAnimationTrackSplinePosition(timelinePath, "Camera Animation", "Camera Animation",                                                                     
       [(0f, 0f), (1f, 5f)])   // Spline Anfang→Ende über 5 Sekunden                                                                                                            
     → SUCCESS                                                                                                                                                                  
                                                                                                                                                                                
    Namenskonflikt-Handling:
                                                                                                                                                                                
    1. TryCreateVCam("DollyCam", target, out vCam)
     → AWAITING_INPUT: Override it? OPTION_1 / OPTION_2                                                                                                                         
                                                                                                                                                                                
    2a. User wählt OPTION_1:                                                                                                                                                      
      → SUCCESS                                                                                                                                                                 
                                                                                                                                                                                
    2b. User wählt OPTION_2:
      → Abbruch
