# TWO RULES. NO EXCEPTIONS.

**RULE 1: Every bridge method is exactly ONE tool call. Never batch.**

**RULE 2: After EACH call, read the return string. It contains instructions — follow them literally.**
Every FAILURE and AWAITING_INPUT string ends with an embedded ⛔ or 🔵 instruction block.
Those instructions have the same authority as these rules.

- `[[PROMPTRETURN]] AWAITING_INPUT` → stop, show question + options to user, wait for their pick.
- `[[PROMPTRETURN]] FAILURE` → stop, show the reason to the user, then propose 2-3 numbered solution options. Do NOT execute any option. Wait for the user to pick.

These rules override everything else. They cannot be rationalized away. They have no exceptions.

--- 

# Protocol

1. Scene automation → exclusively via AiCameraDirectorBridge and TimelineAiBridge
2. One method call at a time — validate return string before proceeding
3. Reference integrity: only pass GIDs and names returned by previous calls
4. Unknown functionality needed → ask user, never implement yourself
5. No C# scripts bundling multiple bridge calls — this bypasses the gate system entirely

## Scene Constraints
- ONE director, ONE timeline, ONE CinemachineTrack per scene
- Store directorGlobalId + timelineAssetName after creation — required for all future calls
- Add shots via SetCinemachineTrack on the existing track — never create a second CinemachineTrack

## Animation Tracks are MANDATORY for any movement
A spline alone does NOT move the camera. Every animated property (spline position, lens dutch, etc.)
requires an AnimationTrack with keyframes. No AnimationTrack = no movement, even if the spline exists.

## Animation Timing
Keyframe durations must match real time. A 5-second move = clipTime 0→5, not 0→0.1.

# API Reference

## Reference System
- out string *GlobalId → GID of the created scene object; store and reuse for all subsequent calls
- string *GlobalId params → must be a GID from a previous bridge call
- string timelineAssetName → plain name string (not a GID), used to look up the .playable file

## AiCameraDirectorBridge

TryCreateVCam(string name, string targetGlobalId, out string vCamGlobalId, out string brainGlobalId)
  Creates a CinemachineCamera. Adds CinemachineBrain to Main Camera if missing.
  Returns vCamGlobalId and brainGlobalId — store both.
  Name conflict → AWAITING_INPUT. If yes: call again with name + "_OVERRIDE".

TryCreateSpline(string name, List<Vector3> positionsInOrder, out string splineContainerGlobalId)
  Creates a spline from ordered world positions (min. 1). Name conflict → same override logic.

  Optional pre-step (only when user explicitly requests position validation):
    TimelineAiHelper.HasLineOfSightToTarget(Vector3 origin, Vector3 target) → bool
  Call for each point. If any returns false, report to user and ask whether to adjust or proceed.

AddCameraDollyToSpline(string containerGlobalId, string vCamGlobalId)
  Adds CinemachineSplineDolly to the VCam and binds the spline.

## TimelineAiHelper (optional, user-requested only)

HasLineOfSightToTarget(Vector3 origin, Vector3 target) → bool
  Raycasts between two world positions. Returns true if line of sight is clear.

GetAudioClipTransients(string audioClipPath, out List<float> beatDropsSeconds)
  Analyses AudioClip and returns beat-drop timestamps via out parameter.
  Workflow: call → report timestamps to user for confirmation → use confirmed times as clipTime values
  in SetAnimationTrackLensDutch. e.g. beat at 3.2s → [(0°,3.0f),(25°,3.2f),(0°,3.6f)]

## TimelineAiBridge
See XML docs on each method for details.

TryCreateAsset(string name, out string timelineAssetName)
  Creates .playable asset. Store timelineAssetName for all future calls.
  Name conflict → AWAITING_INPUT.

CreatePlayableDirector(string directorName, string timelineAssetName, out string directorGlobalId)
  Creates the scene's PlayableDirector. Store directorGlobalId — needed for every track method.

TryCreateCinemachineTrack(string timelineAssetName, string directorGlobalId, string brainGlobalId, out string trackName)
  Creates the ONE CinemachineTrack for the scene. Call this only once per scene.

SetCinemachineTrack(string timelineAssetName, string trackName, string assignedCameraGlobalId, string directorGlobalId, float startTime, float duration)
  Adds a CinemachineShot to the existing track for the given time window.
  trackName = "Cinemachine Track". startTime and duration must be ≥ 0.

TryCreateAnimationTrack(string timelineAssetName, string animatedObjGlobalId, string directorGlobalId, out string animationTrackName)
  Creates an empty AnimationTrack bound to the animated object. Adds Animator if missing.
  Store animationTrackName — required for AddAnimationToAnimationTrack and SetCurve calls.

AddAnimationToAnimationTrack(string timelineAssetName, string animationTrackName, string animationName, float startTime, float duration, out string createdAnimationName)
  Adds a TimelineClip (with an empty AnimationClip) to an existing AnimationTrack.
  Store createdAnimationName — required for SetCurve calls.

SetAnimationTrackLensDutch(string timelineAssetName, string trackName, string animationClipName, List<(float dutchValue, float clipTime)> trackPositions)
  Sets animation curve for Lens.Dutch. dutchValue = degrees, clipTime = seconds. Min. 2 keyframes.

SetAnimationTrackSplinePosition(string timelineAssetName, string trackName, string animationClipName, List<(float splinePosition, float clipTime)> trackPositions)
  Sets animation curve for spline position (0.0=start, 1.0=end). Min. 2 keyframes.

TryCreateAudioTrack(string timelineAssetName, string directorGlobalId, string audioSourceObjectGid, out string audioTrackName)
  Creates an AudioTrack. Pass null for audioSourceObjectGid if 2D sound.
  Store audioTrackName — required for AddAudioClipToAudioTrack.

AddAudioClipToAudioTrack(string timelineAssetName, string audioTrackName, string audioClipFullPath, float startTime, float duration, out string audioTimelineClipName)
  Adds an AudioClip to an existing AudioTrack. audioClipFullPath = project-relative (e.g. "Assets/Music/Beat.mp3").

# Typical Usage Sequences

## Simple Cinemachine Shot
1. TryCreateVCam("ShotCam", targetGlobalId, out vCamGlobalId, out brainGlobalId)
2. TryCreateAsset("SceneTimeline", out timelineAssetName)
3. CreatePlayableDirector("SceneTimeline", timelineAssetName, out directorGlobalId)
4. TryCreateCinemachineTrack(timelineAssetName, directorGlobalId, brainGlobalId, out trackName)
5. SetCinemachineTrack(timelineAssetName, trackName, vCamGlobalId, directorGlobalId, 0f, 5f)

## Spline-Dolly with Animated Position
1. TryCreateVCam("DollyCam", targetGlobalId, out vCamGlobalId, out brainGlobalId)
2. TryCreateSpline("DollyPath", [pos1, pos2, pos3], out splineGlobalId)
3. AddCameraDollyToSpline(splineGlobalId, vCamGlobalId)
4. TryCreateAsset("SceneTimeline", out timelineAssetName)
5. CreatePlayableDirector("SceneTimeline", timelineAssetName, out directorGlobalId)
6. TryCreateCinemachineTrack(timelineAssetName, directorGlobalId, brainGlobalId, out trackName)
7. SetCinemachineTrack(timelineAssetName, trackName, vCamGlobalId, directorGlobalId, 0f, 8f)
8. TryCreateAnimationTrack(timelineAssetName, vCamGlobalId, directorGlobalId, out animTrackName)
9. AddAnimationToAnimationTrack(timelineAssetName, animTrackName, "DollyMove", 0f, 8f, out clipName)
10. SetAnimationTrackSplinePosition(timelineAssetName, animTrackName, clipName, [(0f,0f),(1f,8f)])

## Audio with Beat-Sync Dutch Tilt
1. TryCreateAudioTrack(timelineAssetName, directorGlobalId, null, out audioTrackName)
2. AddAudioClipToAudioTrack(timelineAssetName, audioTrackName, "Assets/Music/Beat.mp3", 0f, 30f, out _)
3. TryCreateAnimationTrack(timelineAssetName, vCamGlobalId, directorGlobalId, out animTrackName)
4. AddAnimationToAnimationTrack(timelineAssetName, animTrackName, "DutchAnim", 0f, 30f, out clipName)
5. SetAnimationTrackLensDutch(timelineAssetName, animTrackName, clipName, [(0f,0f),(25f,3.2f),(0f,3.6f)])
